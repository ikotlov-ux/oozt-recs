# oozt-recs

Автоматизированное формирование природоохранных рекомендаций (мероприятий) для особо охраняемых зелёных территорий (ООЗТ) и природных территорий города Москвы. Скрипт назначает мероприятия по кварталам и выделам на основе ГИС-слоёв, ЦМР и данных о встречаемости видов, для каждого назначения формирует текстовое основание с числовыми значениями и собирает картографические схемы и отчёт.

## Нормативная основа

Перечень мероприятий и их нумерация соответствуют разделу 4 «Мероприятия по сохранению биоразнообразия при проведении работ по содержанию ООЗТ и ПТ» Временного регламента содержания особо охраняемых зелёных территорий и природных территорий города Москвы, утверждённого совместным приказом Правительства Москвы от 30.12.2025 № 05-09-310/25 (и др.), пункты 4.1–4.13. Отдельные позиции соответствуют инженерно-техническим и противоэрозионным мероприятиям (ИПЭЭ-1…ИПЭЭ-3).

## Реализованные правила

| Код | Мероприятие | Пункт | Метод выявления |
| --- | --- | --- | --- |
| I.3 | Создание условий для самовосстановления покрова | 4.3 | плотность троп на выдел (м/га), верхний квартиль по выборке выделов |
| I.7 | Регулируемое мозаичное выкашивание травостоя | 4.9 | все луговые сообщества |
| I.8 | Частичное удаление деревьев и кустарников на болотах | 4.12 | все водные и околоводные сообщества |
| I.9 | Принудительная аэрация | 4.12 | все водные сообщества |
| I.10 | Укрепление берегов | ИПЭЭ-1 | тропы по периметру водных объектов, скользящее окно 50 м |
| II.1 | Удаление чужеродных инвазивных видов растений | 4.1 | точки, полигоны и SDM-растры с вероятностью ≥ 0,95 |
| III.1 | Сохранение почвозащитного подлесочного яруса | 4.2 | растровая плотность троп, скользящее окно 50 м, верхний квартиль |
| III.3 | Ликвидация стихийных троп с восстановлением покрова | 4.3 | тропы в 50 м от точек редких видов, SDM ≥ 0,75 |
| III.4 | Установка временных ограничений рекреации | 4.7 | тропы в 50 м от точек редких видов, SDM ≥ 0,75 |
| III.5 | Защита обезлесенных склонов от эрозии | ИПЭЭ-2 | уклон по ЦМР более 5 % и луговые экосистемы |
| III.5 | Посадка и обработка по горизонталям, террасирование | ИПЭЭ-3 | уклон по ЦМР более 7 %, любые экосистемы |
| IV.5 | Контроль численности врановых в период гнездования | — | плотность точек рода *Corvus*, окно 500 м, верхний квартиль |

Остальные мероприятия раздела 4 в расчёт не входят: часть требует передачи готовых слоёв данных (наблюдения орнитологов и зоологов, слои рубок, дренажной сети, площадок отдыха), часть — разработки метода дистанционного выявления.

## Основные параметры

Задаются константами в начале файла `oozt_recs.py`:

| Параметр | Значение | Смысл |
| --- | --- | --- |
| `CELL` | 10 м | шаг сетки растров плотности и уклона |
| `TRAIL_WINDOW_M` | 50 м | радиус скользящего окна плотности троп |
| `CORVUS_WINDOW_M` | 500 м | радиус окна плотности врановых |
| `RARE_BUFFER_M` | 50 м | буфер от точек редких видов |
| `SHORE_BUFFER_M` | 50 м | буфер вдоль водных объектов для укрепления берегов |
| `SDM_THRESHOLD_RARE` | 0,75 | порог вероятности SDM для редких видов |
| `SDM_THRESHOLD_INVASIVE` | 0,95 | порог вероятности SDM для инвазионных видов |
| `QUANTILE` | 0,75 | «верхний квартиль» для порогов плотности |

Пороги уклона (5 % и 7 %) считываются из формулировки метода в таблице мероприятий.

## Требования

Python 3.10 и новее, окружение с геопространственными пакетами:

```
geopandas, pyogrio, rasterio, shapely, numpy, pandas, scipy, matplotlib, openpyxl
```

Дополнительно: `contextily` — подложка OSM на схемах, `python-docx` — отчёт в формате DOCX (без него отчёт формируется только в Markdown), `tkinter` — диалоговый выбор файлов.

Пример создания окружения:

```bash
conda create -n gis python=3.11 geopandas pyogrio rasterio shapely scipy matplotlib openpyxl contextily -c conda-forge
conda activate gis
pip install python-docx
```

## Запуск

```bash
# диалоговый режим: все пути выбираются в окнах
python oozt_recs.py

# повторный запуск с сохранённой конфигурацией, без диалогов
python oozt_recs.py --config config_local.json

# отчёт только по выбранным кварталам
python oozt_recs.py --config config_local.json --kv 1,2,17,40

# пересобрать только отчёт по уже рассчитанной таблице
python oozt_recs.py --config config_local.json --report-only

# собрать конфигурацию диалогами и выйти
python oozt_recs.py --save-config-only

# без подложки OSM
python oozt_recs.py --config config_local.json --no-basemap
```

Скопируйте `config.example.json` в `config_local.json` и подставьте свои пути. Файлы `config_local*.json`, `config_pc.json` и `config_used.json` исключены из репозитория, чтобы локальные абсолютные пути не попадали в историю.

## Входные данные

Обязательны только таблица мероприятий (`measures_xlsx`) и слой ООЗТ с кварталами и выделами (`oozt_path`). Остальные слои опциональны: соответствующие правила просто пропускаются с записью в журнал.

| Ключ конфигурации | Содержание |
| --- | --- |
| `measures_xlsx` | таблица «Мероприятия по Приказу»: мероприятие, тип экосистемы, пункт, признак включения, метод выявления |
| `oozt_path` | полигоны выделов с атрибутами ООЗТ, квартала, выдела и типа экосистемы |
| `dem_path` | цифровая модель рельефа для расчёта уклонов |
| `trails` | линии дорожно-тропиночной сети (OSM highway или собственные съёмки) |
| `hydro_lines`, `hydro_polys` | линейные и полигональные водные объекты |
| `invasive_points`, `invasive_polys`, `invasive_rasters` | встречаемость инвазионных видов, включая растры SDM |
| `rare_points`, `rare_polys`, `rare_rasters` | встречаемость редких и охраняемых видов, включая растры SDM |
| `fauna_points` | точки наблюдений животных, в том числе рода *Corvus* |

## Результаты

Всё складывается в `out_dir`:

| Файл | Содержание |
| --- | --- |
| `measures_long.xlsx`, `measures_long.csv` | длинная таблица ООЗТ — квартал — выдел — мероприятие с основанием и числовым значением |
| `measures_by_vydel.xlsx` | сводка: одна строка на выдел, мероприятия через разделитель |
| `evidence.gpkg` | слои-основания (точки, линии, полигоны) и выделы с назначенными мероприятиями, EPSG:4326 |
| `report/report.md` | отчёт по кварталам: схема и таблицы мероприятий, сгруппированные по типу мероприятий, типу экосистемы и пункту приказа |
| `report/fig_kv_*.png` | картографические схемы кварталов |
| `config_used.json` | фактическая конфигурация запуска, пригодна для передачи в `--config` |

Координаты в отчётах приводятся в WGS 84 (десятичные градусы), выходные слои сохраняются в EPSG:4326.
